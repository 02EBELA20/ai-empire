# AI Empire: Neural Network Tycoon

Isometric 3D idle tycoon (web first, mobile-first design, apps later).

## Quick start
```
npm install
npm run dev          # local dev server (open on your phone via the shown network URL)
npm test             # unit and integration tests
npm run build        # production build to dist/
npm run build:single # one-file preview build
npm run sim          # economy balance simulator
```
URL options: `?speed=20` fast-forward, `?fresh` ignore save, `?debug` expose `window.__ai`.

Project docs: MASTER_PLAN.md, GAME_DESIGN.md, ECONOMY.md, TECH_ARCHITECTURE.md, DECISIONS.md, HANDOFF.md.
