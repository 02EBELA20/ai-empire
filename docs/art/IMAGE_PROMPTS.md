# Concept Art Prompts — One Per Device Stage

All prompts below are for **concept reference images only**, not direct production meshes. Use the same consistent art direction and fixed camera. Do not include trademarks, text labels, people, UI or watermarks.

**Universal negative prompt:** copied mobile game UI, existing franchise characters, brand logos, unreadable tiny details, excessive bloom, floating parts without support, extreme perspective, photorealistic clutter, background scenery, text, watermark.

**Review:** verify silhouette, four-stage family consistency, connector visibility, feasible mobile geometry and footprint before modeling.
